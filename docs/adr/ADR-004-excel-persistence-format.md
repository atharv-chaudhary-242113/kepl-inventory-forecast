# ADR-004

## Title

Excel Workbook as Persistence Format

## Status

Accepted

## Context

Business users require a portable, reusable output format.

## Decision

Use Excel workbooks as the canonical persistence and interchange format.

## Consequences

Benefits:

* User familiarity
* Offline portability
* Auditability

Tradeoffs:

* Additional export complexity

Excel is a persistence format, not a database.
